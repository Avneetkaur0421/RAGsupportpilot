# Refund approval guide

## Approval limits
Support agents can approve refunds up to $300 on their own. Refunds from $300 to $1,500 need a team lead's approval. Anything above $1,500 needs the operations manager.

## Outside the return window
Returns up to 7 days past the 30-day window can be approved by a team lead as a goodwill exception. Log the reason in the order notes.

## Waiving the return fee
The $99 return fee can be waived once per customer if they report a sizing or fit issue within the first 14 days.
