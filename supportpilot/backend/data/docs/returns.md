# Returns and refunds

## Return window
You can return a bike within 30 days of delivery if it has been ridden less than 50 miles. Accessories can be returned within 30 days if unused and in their original packaging.

## How to start a return
Start a return from the Orders page in your account, or email support with your order number. We send a prepaid return label and a bike box within 3 business days.

## Refund timing
Refunds go back to the original payment method within 5 to 7 business days after the bike reaches our warehouse and passes inspection.

## Return fees
Returns are free for bikes that arrive damaged or defective. For other bike returns, a $99 return shipping fee is deducted from the refund.
